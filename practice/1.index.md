# 📄 1.index — JavaScript DOM Form Access & Manipulation

Is document me JavaScript HTML DOM (Document Object Model) ke through Form elements ko access karne, values extract karne aur dynamic DOM injection (`innerHTML`) ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html>
<body>
    <h2>JavaScript HTML DOM</h2>
    <p>Finding HTML Elements Using <b>document.forms</b>.</p>

    <!-- Target Form -->
    <form id="frm1" action="/action_page.php">
        First name: <input type="text" name="fname" value="Donald"><br>
        Last name: <input type="text" name="lname" value="Duck"><br><br>
        <input type="submit" value="Submit">
    </form> 

    <p>These are the values of each element in the form:</p>
    <p id="demo"></p>

    <!-- JavaScript DOM Extraction Script -->
    <script>
        const formObj = document.forms["frm1"];
        let resultText = "";
        for (let i = 0; i < formObj.length; i++) {
            resultText += formObj.elements[i].value + "<br>";
        }
        document.getElementById("demo").innerHTML = resultText;
    </script>
</body>
</html>
```

---

## 🔑 2. Core Concepts & Explanations

### 1. The `document.forms` Collection
- JavaScript DOM me page ke sabhi forms `document.forms` array-like collection me automatically available hote hain.
- Form ko uski `id` ya `name` se direct target kiya ja sakta hai (e.g. `document.forms["frm1"]`).

### 2. Form Elements Iterator (`form.elements`)
- `formObj.elements`: Form ke andar existing sabhi input fields, checkboxes aur buttons ko represent karta hai.
- `formObj.elements[i].value`: Specific field me user dwara entered text / current value ko read karta hai.

### 3. Dynamic DOM Output (`innerHTML`)
- `document.getElementById("demo").innerHTML = resultText;`: Form se fetch kiye gaye data ko format karke dynamically `#demo` paragraph ke andar inject kar deta hai bina page reload kiye.
