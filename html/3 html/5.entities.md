# 📄 5.entities — HTML Entities & Preformatted Text (`<pre>`)

Is document me HTML Reserved Characters Escaping (Entities) aur Exact Spacing / Indentation Preservation (`<pre>`) ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Entities</title>
</head>
<body>
    <!-- Displaying reserved tags -->
    &lt;p&gt;&lt;/p&gt;

    <!-- Preformatted text preserving spaces and enters -->
    <pre>
    This is line 1
          This is indented line 2
    </pre>

    <!-- Multiple non-breaking spaces and copyright -->
    <p>Copyright &copy;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;CodeWithHarry</p>

    <!-- Mathematical symbol -->
    <p>The price is 10 &lt; 20.</p>
</body>
</html>
```

---

## 🔑 2. Core Concepts & Explanations

### 1. Why HTML Entities?
- HTML me `<` aur `>` jaise symbols tags create karne ke liye reserved hote hain. Agar aap directly `<p>` likhenge to browser use code tag maan kar execute kar dega na ki screen par text ki tarah print karega.
- Reserved characters aur symbols ko screen par display karne ke liye **HTML Entities** use ki jati hain.

### 2. Common HTML Entities Table

| Entity Name | Entity Number | Result Character | Description |
| :--- | :--- | :--- | :--- |
| `&lt;` | `&#60;` | `<` | Less Than |
| `&gt;` | `&#62;` | `>` | Greater Than |
| `&amp;` | `&#38;` | `&` | Ampersand |
| `&quot;` | `&#34;` | `"` | Double Quote |
| `&apos;` | `&#39;` | `'` | Single Quote |
| `&nbsp;` | `&#160;` | ` ` | Non-Breaking Space (forces extra space) |
| `&copy;` | `&#169;` | `©` | Copyright Symbol |
| `&reg;` | `&#174;` | `®` | Registered Trademark |
| `&trade;` | `&#8482;` | `™` | Trademark Symbol |

### 3. Preformatted Text (`<pre>`)
- HTML normal text me multiple spaces aur enter (line breaks) ko single space me collapse kar deta hai.
- `<pre>` tag ke andar text ke exact spaces, indentation aur newlines bina collapse huye monospace font me display hote hain.
