# 📄 3.video and audio — HTML5 Multimedia, SVG Vectors & Iframes

Is document me HTML5 Video (`<video>`), Audio (`<audio>`), `preload` caching policies, Scalable Vector Graphics (`<svg>`) aur Inline Frames (`<iframe>`) ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Video, Audio, SVG & Iframe</title>
</head>
<body>
    <!-- Video Player with Poster -->
    <div>
        <video src="video.mp4" width="400" height="300" poster="nature.jpg" controls muted loop></video>
    </div>

    <!-- Audio Player with Preload Strategy -->
    <div>
        <audio src="alvida.mp3" controls loop preload="auto"></audio>
    </div>

    <!-- SVG Vector Circle -->
    <div>
        <svg height="100" width="100">
            <circle cx="50" cy="50" r="40" stroke="black" stroke-width="3" fill="red" />
        </svg>
    </div>

    <!-- Embedded Iframe -->
    <div>
        <iframe src="https://example.com" width="500" height="300" allow="fullscreen"></iframe>
    </div>
</body>
</html>
```

---

## 🔑 2. Core Concepts & Explanations

### 1. HTML5 Video Tag Attributes
- `src`: Video file ka path.
- `controls`: Native play, pause, seekbar, volume aur fullscreen controls.
- `autoplay` & `muted`: Page load par video auto-start karta hai (modern browsers bina `muted` ke autoplay block kar dete hain).
- `loop`: Video khatam hote hi starting se replay karta hai.
- `poster="nature.jpg"`: Video play hone se pehle preview thumbnail image dikhata hai.
- `width` & `height`: Visual layout dimensions.

### 2. HTML5 Audio Tag & `preload` Values
- `controls`: Audio play/pause controls.
- `preload="..."`: Browser ko file download caching strategy batata hai:
  - `none`: User ke play button dabane se pehle bilkul audio download nahi karta (data saving).
  - `metadata`: Sirf duration, track length aur basic header info download karta hai.
  - `auto`: Background me poori audio file download karke browser cache me ready rakhta hai taaki click karte hi bina buffer ke play ho.

### 3. Scalable Vector Graphics (`<svg>`)
- **Meaning**: XML-based vector graphics format jo kisi bhi screen resolution (Retina, 4K) par bina pixelate/blur huye infinitely zoom ho sakta hai.
- **`<circle>` Anatomy Breakdown**:
  - `cx="50"`, `cy="50"`: Center coordinate position (X-axis aur Y-axis par 50px offset).
  - `r="40"`: Radius 40px (diameter = 80px).
  - `stroke="black"` & `stroke-width="3"`: Border outline color black aur 3px thickness.
  - `fill="red"`: Circle ke andar ka solid color red.

### 4. Inline Frames (`<iframe>`)
- Ek webpage ke andar kisi doosri external webpage, YouTube video ya Google Map ko embed karne ke liye use hota hai.
