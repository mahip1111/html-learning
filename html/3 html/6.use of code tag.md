## 🔑 2. Core Concepts & Explanations

### 1. The `<code>` Tag
- **Semantic Purpose**: Computer programming code snippets, variable names ya commands ko semantically define karta hai.
- **Default Font**: Browser ise by default monospaced font (Courier / Consolas) me render karta hai.

### 2. Combining `<pre>` and `<code>`
- `<pre>` $\rightarrow$ Spaces aur Line Breaks ko preserve karta hai.
- `<code>` $\rightarrow$ Monospace code styling aur semantic recognition provide karta hai.
- Dono ko combine karke multi-line code blocks display kiye jate hain (`<pre><code>...</code></pre>`).

### 3. Entity Escaping Inside Code Blocks
- Code block ke andar bhi HTML syntax symbols (`<` aur `>`) ko `&lt;` aur `&gt;` me escape karna padta hai, warna browser unhe actual HTML tags samajh kar parse karne lagega.
