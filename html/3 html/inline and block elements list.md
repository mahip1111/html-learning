# 📄 Inline and Block Elements Reference List

Is document me HTML ke sabhi Block-level aur Inline elements ki categorized quick-lookup reference list di gayi hai.

---

## 🧱 1. Block-Level Elements List

Block elements hamesha nayi line se shuru hote hain aur 100% available horizontal width occupy karte hain:

- `<address>`: Contact information
- `<article>`: Self-contained composition (article/post)
- `<aside>`: Tangentially related content / sidebar
- `<blockquote>`: Long quotation block
- `<canvas>`: Scriptable 2D/3D graphics rendering canvas
- `<dd>`: Definition / description details
- `<div>`: Generic document division container
- `<dl>`: Description list wrapper
- `<dt>`: Description term
- `<fieldset>`: Form controls grouping box
- `<figcaption>`: Figure caption
- `<figure>`: Figure illustration container
- `<footer>`: Page / section footer
- `<form>`: Interactive user input form
- `<h1>` to `<h6>`: Heading hierarchy
- `<header>`: Page / section introductory banner
- `<hr>`: Thematic horizontal rule
- `<li>`: List item
- `<main>`: Central content of document
- `<nav>`: Navigation links wrapper
- `<noscript>`: Fallback for disabled JavaScript
- `<ol>`: Ordered (numbered) list
- `<p>`: Paragraph
- `<pre>`: Preformatted text
- `<section>`: Generic thematic section
- `<table>`: Data table
- `<tfoot`, `<thead>`, `<tbody>`: Table structural groups
- `<ul>`: Unordered (bulleted) list
- `<video>`: Media player container

---

## 🔗 2. Inline Elements List

Inline elements nayi line create nahi karte aur sirf apne content jitni width occupy karte hain:

- `<a>`: Hyperlink anchor
- `<abbr>`: Abbreviation
- `<b>`: Bold styling without extra importance
- `<bdo>`: Bi-directional override
- `<button>`: Clickable button
- `<cite>`: Title of a creative work
- `<code>`: Computer code fragment
- `<dfn>`: Defining instance of a term
- `<em>`: Emphasized stress text
- `<i>`: Italic voice / tone
- `<img>`: Image embed
- `<input>`: Form input control
- `<kbd>`: Keyboard key input
- `<label>`: Form control caption
- `<mark>`: Highlighted text
- `<q>`: Short inline quote
- `<samp>`: Sample computer output
- `<select>`: Dropdown selection box
- `<small>`: Side comments / small print
- `<span>`: Generic inline styling wrapper
- `<strong>`: Strong semantic importance
- `<sub>`: Subscript text ($H_2O$)
- `<sup>`: Superscript text ($X^2$)
- `<textarea>`: Multi-line text input
- `<time>`: Machine-readable datetime
