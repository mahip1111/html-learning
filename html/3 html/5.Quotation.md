# 📄 5.Quotation — Quotations & Citations (`<q>` vs `<blockquote>`)

Is document me HTML Short Inline Quotes (`<q>`), Long Block Quotes (`<blockquote>`), Citation attributes (`cite`) aur Abbreviations (`<abbr>`) ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Quotations</title>
</head>
<body>
    <!-- Short Inline Quote -->
    <p>Albert Einstein said, <q cite="https://example.com/einstein">Imagination is more important than knowledge.</q></p>

    <!-- Long Block Quote -->
    <blockquote cite="https://en.wikipedia.org/wiki/Steve_Jobs">
        Your time is limited, so don't waste it living someone else's life. 
        Don't be trapped by dogma — which is living with the results of other people's thinking.
    </blockquote>
</body>
</html>
```

---

## 🔑 2. Core Concepts & Explanations

### 1. Short Inline Quotation (`<q>`)
- **Use Case**: Kisi sentence ke andar chote direct quote ke liye.
- **Browser Behavior**: Browser iske charon taraf automatically double quotation marks (`“...”`) apply kar deta hai.

### 2. Long Block Quotation (`<blockquote>`)
- **Use Case**: Kisi doosre source se liye gaye lambe multi-line paragraph quotes ke liye.
- **Browser Behavior**: Browser is block ko nayi line par render karta hai aur left aur right dono taraf automatic indentation (margin) provide karta hai.

### 3. The `cite` Attribute
- `<blockquote cite="https://...">` ya `<q cite="https://...">`:
  - Quotation ke original source document ka URL specify karta hai.
  - Ye link visually clickable nahi hota, par search engines aur crawlers ke liye semantic provenance identify karta hai.
