# 📄 4.semantic tags — HTML5 Semantic Layout Architecture

Is document me HTML5 ke Semantic Layout Elements, SEO benefits, Accessibility advantages aur modern page structuring ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Semantic Tags</title>
</head>
<body>
    <!-- Top Header & Navigation -->
    <header>
        <nav>
            <ul>
                <li>Home</li>
                <li>About</li>
                <li>Contact</li>
            </ul>
        </nav>
    </header>

    <!-- Main Page Content -->
    <main>
        <h1>What are Semantic Tags</h1>
        <article>
            <h2>Semantic Web Overview</h2>
            <p>Semantic tags describe their meaning to both browser and developer.</p>
        </article>
    </main>

    <!-- Footer Area -->
    <footer>
        <p>&copy; 2026 All Rights Reserved.</p>
    </footer>
</body>
</html>
```

## 🔑 2. Core Concepts & Explanations

### 1. Semantic vs Non-Semantic Tags
- **Non-Semantic Tags** (`<div>`, `<span>`): Sirf generic boxes banate hain, content ke meaning ya context ke baare me browser ko kuch nahi batate.
- **Semantic Tags** (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`): Tag ke naam se hi saaf ho jata hai ki uske andar kya content hai.

### 2. Major Semantic Tags Reference

| Semantic Tag | Real-world Purpose & Meaning |
| :--- | :--- |
| `<header>` | Page ya section ka top introductory banner (logo, site title, search bar) |
| `<nav>` | Main website navigation links container |
| `<main>` | Webpage ka central, unique content area (har page par ideal sirf 1 `<main>` hona chahiye) |
| `<section>` | Ek thematic group of content (e.g. Features section, Pricing section) |
| `<article>` | Self-contained, independently distributable content (e.g. blog post, news story) |
| `<aside>` | Sidebar content ya indirectly related links |
| `<footer>` | Page ka bottom footer (copyright notices, contact info, privacy policies) |
| `<figure>` & `<figcaption>` | Media/charts ko unke descriptive caption ke sath link karna |
| `<time>` | Dates, clock time ya timestamps ko machine-readable format me show karna |

### 3. Benefits of Semantic HTML
1. **Search Engine Optimization (SEO)**: Google crawlers page ki hierarchy ko accurately index kar pate hain.
2. **Accessibility (a11y)**: Screen readers visually impaired users ko direct navigation landmarks provide karte hain.
3. **Clean Code & Maintainability**: Developers ke liye codebase padhna aur maintain karna bahut easy ho jata hai.
