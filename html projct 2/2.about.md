# 📄 2.about — About Page Architecture (Multi-Page Website)

Is document me About Me page structure, bio introduction aur ordered goals list ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html>
<head>
  <title>About - My Website</title>
</head>
<body>
  <h1>About Me</h1>
  <hr>

  <!-- Global Navigation -->
  <a href="1.index.html">Home</a> 
  <a href="2.about.html">About</a> 
  <a href="3.contact.html">Contact</a> 
  <a href="4.services.html">Services</a>

  <hr>

  <p>Hello! I am learning web development and making projects using HTML.</p>

  <h3>My Goals</h3>
  <ol>
    <li>Become Frontend Developer</li>
    <li>Learn React</li>
    <li>Get Internship</li>
  </ol>
</body>
</html>
```

---

## 🔑 2. Core Concepts
- Consistent navigation retain karte huye sequential career roadmap display karne ke liye `<ol>` tag ka use.
