# 📄 3.contact — Contact Page Architecture (Multi-Page Website)

Is document me Contact Us page layout aur form submission structure ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html>
<head>
  <title>Contact - My Website</title>
</head>
<body>
  <h1>Contact Me</h1>
  <hr>

  <!-- Global Navigation -->
  <a href="1.index.html">Home</a> 
  <a href="2.about.html">About</a> 
  <a href="3.contact.html">Contact</a> 
  <a href="4.services.html">Services</a>

  <hr>

  <form>
    <label>Your Name:</label>
    <input type="text" placeholder="Enter name"><br><br>

    <label>Your Email:</label>
    <input type="email" placeholder="Enter email"><br><br>

    <label>Your Message:</label><br>
    <textarea rows="5" cols="40" placeholder="Enter message"></textarea><br><br>

    <button type="submit">Send Message</button>
  </form>
</body>
</html>
```

---

## 🔑 2. Core Concepts
- Static website me user messaging UI facilitate karne ke liye form inputs aur multiline `<textarea>` controls.
