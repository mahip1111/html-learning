# 📄 1.index — Home Page Architecture (Multi-Page Website)

Is document me multi-page website ke Home Page ka layout, relative navigation header aur highlight lists ke concepts explain kiye gaye hain.

---

## 🎯 1. Code Architecture

```html
<!DOCTYPE html>
<html>
<head>
  <title>Home - My Website</title>
</head>
<body>
  <h1>Welcome to My Website</h1>
  <hr>

  <!-- Global Navigation Bar -->
  <h3>Navigation</h3>
  <a href="1.index.html">Home</a> 
  <a href="2.about.html">About</a> 
  <a href="3.contact.html">Contact</a> 
  <a href="4.services.html">Services</a>

  <hr>

  <h2>Home Page</h2>
  <p>This is a multi-page website made using only HTML.</p>

  <h3>Highlights</h3>
  <ul>
    <li>No CSS</li>
    <li>No JavaScript</li>
    <li>Pure HTML Project</li>
  </ul>
</body>
</html>
```

---

## 🔑 2. Core Concepts
- **Relative Linking Navigation**: Sabhi pages ke beech common navigation menu establish karta hai.
- **Page Specific Title**: `<title>Home - My Website</title>` tab identifying identifier provide karta hai.
